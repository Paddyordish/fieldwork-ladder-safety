# FIELDWORK 001 — Ladder Safety

**Inspect Before You Climb** · Interactive workplace learning · HTML5

**[Launch the interactive demonstration](https://paddyordish.github.io/fieldwork-ladder-safety/)**

A short, bespoke eLearning experience exploring pre-use checks and safe decisions when working with leaning ladders. Built as a portfolio demonstration of interaction-led learning rather than a conventional slide-based course.

## The experience

Across five stages, learners explore a ladder through **four interactive inspection points**, consider a workplace safety decision and answer safe-setup questions. The experience combines visual exploration with feedback and short knowledge checks.

**Highlights**
- Interactive inspection markers with an alternative text-based checklist
- Decision-making and questions with immediate feedback
- Optional recorded narration, ambient music and interface sound controls
- Responsive layout, stage navigation and visible progress
- Keyboard-operable controls, skip link, accessible text alternatives and readable narration transcripts

## Built with

HTML, CSS and JavaScript, with media assets and AI-assisted implementation using Codex. The published demonstration runs as a standalone website on GitHub Pages; no login or LMS is needed to explore it.

**Progress and LMS tracking are different things.** This public version can remember progress **within the current browser-tab session**, where browser storage is available. It does **not** report learner identity, completion, scores or progress to an LMS and is **not a SCORM package**. SCORM distribution and testing are handled separately from this public repository.

## Accessibility and scope

The course provides keyboard navigation, an inspection checklist as an alternative to image markers, text equivalents for narration, and independently controlled optional audio. These are implemented provisions, **not a claim of formal WCAG conformance or an accessibility audit**.

This is a short **awareness demonstration**, not a complete ladder inspection checklist, practical competency assessment or replacement for employer risk assessments, manufacturer instructions or task-specific training. It focuses on a leaning/extension ladder and does not teach stepladder-specific checks.
